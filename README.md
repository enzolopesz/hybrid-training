# HYBRID — Meu Treino (GitHub Pages)

Checklist e histórico dos treinos A, B e C + registro de corridas no Runna.

## Publicar grátis no GitHub Pages

1. No GitHub, crie um repositório **público** chamado `treino-hibrido`.
2. Extraia este ZIP e envie **todos os arquivos de dentro** desta pasta para a **raiz do repositório**. Não envie o arquivo ZIP fechado nem uma pasta extra. O arquivo `index.html` precisa ficar na raiz.
3. Confirme o commit na branch `main`.
4. Abra **Settings > Pages**. Em **Build and deployment > Source**, escolha **Deploy from a branch**; em Branch, marque **main** e **/(root)**; clique **Save**.
5. Aguarde a publicação e abra `https://SEU_USUARIO.github.io/treino-hibrido/` (substitua SEU_USUARIO).

Se preferir usar Git no terminal:

```bash
git init
git add .
git commit -m "Publicar app de treino"
git branch -M main
git remote add origin https://github.com/SEU_USUARIO/treino-hibrido.git
git push -u origin main
```

## Adicionar ao iPhone

No Safari, abra o link do GitHub Pages, toque no botão **Compartilhar > Adicionar à Tela de Início**, ative **Abrir como App** se aparecer e confirme. Abra sempre pelo mesmo ícone para manter o mesmo histórico local.

## Persistência e backup

- Cada série e corrida fica salva automaticamente no **armazenamento local** do Safari ou do aplicativo instalado.
- GitHub Pages **não é banco de dados**: não sincroniza as cargas entre aparelhos nem entre o Safari e um atalho instalado como app; esses ambientes podem ter armazenamentos distintos.
- Na aba **Backup**, exporte periodicamente o histórico JSON e guarde no iCloud Drive. Também há exportação CSV.
- Para migrar, abra o novo aparelho/app e use **Restaurar backup** com o JSON.
- O site é estático e pode funcionar offline depois de carregado/instalado. Para atualizar os arquivos depois de publicar alterações, atualize a página com acesso à internet.

## Ficha

Segunda: Superiores A; terça: corrida leve (Runna); quarta: Inferiores B; quinta: Superiores C; sexta: Runna qualidade; sábado: descanso; domingo: Runna longão.

Terra romeno foi substituído por extensão de quadril no banco 45°. Confira a semana da prova de 8 km e reduza pernas quando necessário.
